# REDES2_2S2026_202300335

Repositorio del curso **Redes de Computadoras 2** — USAC, Facultad de Ingeniería.

## Proyecto 1: Chapin Red

Diseño e implementación de una red corporativa multi-edificio en Cisco Packet Tracer
para la organización **Chapin Red**, aplicando VLANs, VTP, agregación de enlaces
(LACP/PAgP), enrutamiento dinámico (EIGRP), DHCP con Relay y control de acceso (ACLs).

Todo el desarrollo, documentación técnica y capturas están en [`Proyecto1/`](Proyecto1/).

- Carné: **202300335**
- Redes base asignadas: `192.188.35.0/24` (VLANs) y `10.4.35.0/24` (enlaces de enrutamiento)
- Protocolo de enrutamiento: **EIGRP** (carné termina en dígito impar)
